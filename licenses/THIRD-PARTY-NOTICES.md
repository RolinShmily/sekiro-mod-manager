## 2. Sekiro Mod Engine (ModEngine) — NOT redistributed

**No license text is included here because this component is not shipped in any form.**

Sekiro Mod Engine (`dinput8.dll`) by katalash was previously embedded in this project via
`include_bytes!` and written into the user's game directory. That redistribution has been **removed**
because upstream grants no license for it:

| Check | Result |
| :--- | :--- |
| `api.github.com/repos/katalash/ModEngine/license` | **HTTP 404** |
| GitHub API `repos/katalash/ModEngine` → `license` | `null` |
| Repository root contents | no `LICENSE` file |
| ModEngine's own bundled readme | `ModEngine code is (C) 2020 Katalash. All rights reserved.` and `You are free to distribute and UNMODIFIED ModEngine WITH a mod…` |

SMM is a mod manager rather than a mod, and deploys the hook independently of any particular mod, so
the readme's narrow grant does not cover it. SMM therefore no longer embeds, bundles, or deploys any
ModEngine binary. Current behaviour (`crates/smm-core/src/doctor.rs`):

- `install_mod_engine()` requires a **user-supplied** `dinput8.dll` (validated as >10 KB) and returns
  `SmmError::ModEngineSourceMissing` otherwise — it never fabricates or embeds a hook DLL.
- `provision_mod_engine()` likewise requires a user-supplied payload.
- `modengine.ini` is generated by SMM itself (`patch_or_create_modengine_ini`); the upstream INI and
  its `readme.txt` are no longer copied.
- `ModInfo.license` for the engine entry is left `None`, since asserting any license on upstream's
  behalf would be inaccurate.

Users obtain ModEngine from <https://www.nexusmods.com/sekiro/mods/6> or
<https://github.com/katalash/ModEngine>.

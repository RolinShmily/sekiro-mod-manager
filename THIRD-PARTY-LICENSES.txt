      Vendored via unrar_sys 0.5.8; statically linked into smm.exe and
      Sekiro-Mod-Manager.exe.
      License: UnRAR freeware license (non-OSI)     -> section 4

      Used for READ-ONLY RAR extraction only. Clause 2 of that license forbids
      using this code to develop a RAR (WinRAR) compatible archiver, so SMM must
      never implement RAR compression while this dependency is present. Ship .zip
      archives instead.

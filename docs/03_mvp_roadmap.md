# 03. MVP 研发路线图与功能演进规划

> 本文档明确 Sekiro Mod Manager (SMM) 的研发阶段演进路径，划定 Phase 1 (MVP) 的验收指标、后续功能迭代计划，并严肃确立工程红线与非目标（Non-Goals）。

---

## 1. 研发阶段规划总览

```
[ Phase 1: MVP 极简闭环 ] ➔ 验证核心假设：零残留、智能归一化、硬链接秒级装卸
           │
           ▼
[ Phase 2: 冲突视窗与资产安全 ] ➔ 强化透明度：文件级遮蔽透视、参数冲突高危警报、环境自愈
           │
           ▼
[ Phase 3: 进阶辅助与生态互联 ] ➔ 拓展效率：多配置方案 (Profile)、WitchyBND 参数辅助联动
```

---

## 2. Phase 1 (MVP)：极简核心闭环

**核心使命**：用最少代码打通“导入 ➔ 修复 ➔ 排序 ➔ 部署 ➔ 还原”的黄金链路，解决玩家最痛苦的手动解压与目录污染问题。

### 2.1 交付功能清单
1. **游戏运行环境探测与引导 (Environment Preflight Check)**：
   - 自动扫描注册表或 Steam 默认库目录，定位 `sekiro.exe`。
   - 检查游戏根目录下是否存在 `dinput8.dll` 及 `modengine.ini`。
   - 校验 `modengine.ini` 内 `enabled=1` 与 `modOverrideDirectory="\mods"` 配置。若缺失，给予一键复制预制补丁或高亮修复指引。
2. **Mod 资产包导入与启发式归一化 (Smart Ingestion)**：
   - 支持拖拽 `.zip` / `.7z` / `.rar` 压缩包或散装文件夹进管理器。
   - 运行归一化扫描引擎，自动识别 `parts` / `chr` / `param` / `sound` / `msg` 等目录指纹，剔除作者包装的多余父级文件夹，自动封装入独立 Staging 目录并生成唯一 Mod ID。
3. **启停控制与优先级队列 (Order & Toggle)**：
   - 清晰展现 Mod 列表，提供单个 Mod 的“启用 / 禁用”复选开关。
   - 基础的向上/向下调整顺序或拖拽列表，高优先级的 Mod 位于上方。
4. **NTFS 硬链接一键部署与原子化清空 (Deploy & Clean)**：
   - “一键部署”按钮：根据启用状态与优先级，0.5 秒内将硬链接投射至 `Sekiro/mods/`。
   - “清空还原”按钮：清空 `Sekiro/mods/` 内的一切文件，使游戏无痕恢复为纯净原版状态。
5. **同盘卷引导策略**：
   - 检测到 Staging 与游戏目录不在同一驱动器时，提供一键引导将 Staging 设在游戏同卷目录，避免权限异常与性能折损。

### 2.2 Phase 1 验收标准 (DoD)
- [x] 成功导入 5 种不同打包格式的典型只狼 Mod（含深层嵌套、散装根目录），均能自动识别出正确资产结构。
- [x] 在安装 20 个 Mod（总计体积超 5GB）的情况下，“一键部署”耗时小于 1 秒，“一键清空”耗时小于 0.5 秒。
- [x] 部署后启动游戏，替换的角色模型与武器外观正常生效，退出游戏清空后，游戏无任何残留文件。

## 3. Phase 2：冲突视窗与资产安全

**核心使命**：让用户直观“看见” Mod 之间的相互覆盖关系，杜绝黑盒隐患，提供安全快照保护。

### 3.1 规划功能清单
1. **文件级冲突透视视窗 (Conflict Inspector)**：
   - 在 UI 上直观展示哪些 Mod 的哪些文件发生了重叠覆盖。
   - 明确标注胜出者（Winner）与被遮蔽者（Shadowed），并提示用户通过调整优先级来调换胜出方。
2. **核心参数高危冲突专用警报**：
   - 针对 `param/gameparam/gameparam.parambnd.dcx` 设立专属高亮警示徽章。
   - 当检测到两个及以上启用的 Mod 均包含该文件时，弹出警告气泡：“检测到核心数值表冲突，上方 Mod 将完全覆盖下方 Mod 的平衡性修改！”
3. **模型槽位独占提示 (Slot Collisions)**：
   - 自动识别主角常用槽位（`am_m_9000` 义手、`bd_m_9000` 身体、`wp_a_0300` 楔丸）。
   - 标记外观 Mod 之间的槽位抢占冲突，推荐用户保持单一生效。
4. **一键快照与本地备份 (Snapshot & Backup)**：
   - 部署前自动记录当前部署状态为 Manifest 快照。
   - 支持随时导出/导入当前已启用的 Mod 组合清单。

## 4. Phase 3：进阶辅助与生态互联

**核心使命**：连接 FromSoftware 极客工具链，满足中高级玩家的多玩法配置与参数微调诉求。

### 4.1 规划功能清单
1. **多配置预设切换 (Profiles Management)**：
   - 支持建立多个独立的方案，例如：“纯外观增强方案”、“只狼：复活 (Resurrection) 机制方案”、“只狼：长须 (Longshanks) 硬核方案”。
   - 切换方案时一键自动重排优先级并重新投影部署。
2. **外部参数合并工具联动 (WitchyBND / Yabber Linkage)**：
   - 针对 `gameparam.parambnd.dcx`，提供“在外部工具中打开”辅助按钮。
   - 自动调用系统已安装的 WitchyBND 解包两个冲突 Mod 的 Param 为 XML，辅助玩家使用 VS Code / Beyond Compare 手动合并差异行。
3. **多语言缺失检测与自动对齐 (Localization Fallback)**：
   - 检测 Mod 是否仅存在 `msg/engus` 但缺少 `msg/zhocn`。
   - 提供快捷选项：“将英文字符串包自动复制为简体中文包”，防止国内玩家在游戏中遭遇全屏无字或问号乱码。

## 5. 显式非目标 (Explicit Non-Goals)

为了确保软件极致精炼并保证研发交付期，本项目确立以下**坚决不做的边界**：

```
+-------------------------------------------------------------------------+
|                         显式非目标 (Non-Goals)                           |
+-------------------------------------------------------------------------+
|  [x] 绝对不做多游戏通用抽象 (No Multi-Game Generalization)               |
|      - 拒绝引入 Skyrim / Cyberpunk 等异构游戏的复杂抽象层                 |
|      - 代码库中不保留对其他游戏的兼容性扩展槽                             |
+-------------------------------------------------------------------------+
|  [x] 绝对不做内置 3D 模型 / 贴图渲染器 (No Built-in 3D Preview)         |
|      - 不在管理软件内解析 FLVER / TPF / BND 并渲染 3D 视图                |
|      - 资产展示仅基于文件树、图片预览（若 Mod 自带封面）或元数据          |
+-------------------------------------------------------------------------+
|  [x] 绝对不做游戏进程动态注入与作弊修改 (No Memory Hack / Injection)    |
|      - 不碰 Sekiro 进程内存，不提供免 CD / 破解功能                       |
|      - 部署过程仅在游戏启动前完成静态文件挂载                             |
+-------------------------------------------------------------------------+
|  [x] 不在 Phase 1 强行内置全自动三路参数合并引擎 (No Auto Param Merge)    |
|      - FromSoft 的 GameParam 二进制合并极其繁琐且版本敏感                  |
|      - 盲目自动化合并可能损坏游戏存档，前期坚持“高危预警 + 外部工具辅助”  |
+-------------------------------------------------------------------------+
|  [x] 不做内置的 Mod 资源下载市场与爬虫 (No Built-in Mod Hub)             |
|      - 遵守 NexusMods 使用协议，不侵权抓取用户凭证                        |
|      - 仅专注本地离线管理，输入来源由用户自主下载                         |
+-------------------------------------------------------------------------+
```

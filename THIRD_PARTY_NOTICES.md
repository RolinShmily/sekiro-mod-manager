### HuskarUI

- Upstream: https://github.com/mengps/HuskarUI
- Licence: MIT — Copyright (c) 2024 mengps (MenPenS)
- Text: `third_party/HuskarUI/LICENSE` (inside the submodule)
- Used for: the entire QML component library behind `smm_gui` (Ant-Design-style controls:
  `HusWindow`, `HusButton`, `HusCard`, `HusModal`, `HusDrawer`, `HusSelect`, `HusSwitch`,
  `HusSegmented`, `HusEmpty`, `HusTag`, `HusDivider`, `HusInput`, `HusIconText`, …), plus the
  `HuskarUI-Icons` icon font and the theme token system (`HusTheme`).
- Linked as a **static** library (`HUSKARUI_STATIC_LIBRARY=ON`) so no HuskarUI DLL has to ship
  next to `smm_gui`. Static linking means the QML plugin's `initializeEngine` does not run, so
  `HusApp::initialize()` is called explicitly from `src/gui/main.cpp` — without it the icon font
  is never registered and every `HusIconText` glyph renders blank.
- **Local patch (uncommitted in the submodule):** `src/imports/HusSegmented.qml` divides by the
  model count when `block: true` to share width between segments. On the first layout pass the
  count is still 0, so the division produced a non-finite value and Qt aborted on
  `Q_ASSERT(value < maximalPlusOne)` in `qnumeric.h`. The patch guards the count and clamps to 0,
  and also avoids reading `parent.width` before the parent is laid out. If the submodule is ever
  re-checked-out from upstream, this patch must be reapplied or a `block`-mode `HusSegmented`
  will crash the GUI on open.

## Not bundled, on purpose

### ModEngine (dinput8.dll)

SMM detects, configures and installs ModEngine, but **never ships it**. katalash's ModEngine
publishes no licence and reserves all rights, so redistributing the DLL would not be lawful; and an
unmodified copy bundled with a mod is the only redistribution its author permits.

`doctor` and `setup-engine` therefore require a genuine `dinput8.dll` (over 10 KB) to already exist
in the ModEngine source folder or in `staging/mod-engine/`, and report where to obtain it
(https://www.nexusmods.com/sekiro/mods/6) when it does not.

### Qt 6

- Upstream: https://www.qt.io/
- Licence: LGPLv3 (or GPLv3, or commercial)
- Used for: the GUI only. The core and CLI do not link Qt at all.
- Qt is dynamically linked, not vendored, and is expected to be provided by the user's Qt
  installation — which is what LGPLv3 requires for a proprietary or MIT-licensed consumer. Anything
  that ships a binary of `smm_gui` must keep Qt as a replaceable shared library and reproduce the
  LGPLv3 notice and the Qt source offer.

### 7-Zip / WinRAR

- `7z.exe` and `unrar.exe` are invoked as external processes when the user asks to import a `.7z`
  or `.rar` package. Nothing is linked against them and nothing is redistributed. `.zip` needs no
  external tool.

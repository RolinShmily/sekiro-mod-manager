## Overview

This mod replaces the standard Xbox button prompts in *Sekiro: Shadows Die Twice* with native PlayStation 4 (DualShock 4) prompt icons.

## Directory Structure and Asset Coverage
- `menu/hi/01_common.tpf.dcx`: High-resolution texture pack container with PlayStation Cross, Circle, Square, Triangle, L1/R1, L2/R2, and D-pad prompt icons.
- `menu/menu.menubnd.dcx`: Menu definition binder for prompt alignments.
- `font/font_ps4.gfx`: Scaleform Flash vector font mappings for controller glyphs.

## Conflict Characteristics
- Safe UI resource override. Collisions with other HUD mods can be cleanly resolved via manager priority.
